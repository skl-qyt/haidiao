# 海钓时刻助手 · 广西沿海智能钓鱼推荐

> 今晚花 10 秒：选城市 → 选海边钓点，潮水、风向、水温自动算出明天最该下竿的 3 小时。

**在线使用**：https://skl-qyt.github.io/haidiao/

手机打开后可「添加到主屏幕」当 App 用（PWA）：桌面图标、全屏、断网可查潮汐与鱼种（仅实时天气需要网络）。

---

## 功能

| 板块 | 说明 |
|---|---|
| 问明天 | 选城市（北海/防城港/钦州）→ 选钓点，输出最佳时段 + 钓鱼指数 + 两个备选时段，可生成分享卡 |
| 作钓记录 | 五档条数（爆护 10+ / 丰收 6–9 / 有口 3–5 / 零星 1–2 / 空军 0）+ 鱼获详情 + 照片（自动压缩），攒够 5 笔自动分析「你的黄金时段」，可导出 CSV |
| 全天评分曲线 | 明天/后天/大三天 05:00–22:00 逐小时指数，主推荐时段高亮，触屏滑动查看 |
| 钓点交互地图 | 12 个核心钓点：类型、危险等级、目标鱼、停车、新手友好度；支持双钓点对比 |
| 潮汐预报 | 大潮/小潮日历 + 未来 7 天逐日实测表，双潮日显示两组高低潮 |
| 鱼种季节图谱 | 17 种目标鱼 × 12 月热力图，点开看钓法、饵料、常见体型 |

## 评分模型

潮汐 45% + 水温 35% + 风向 20%，叠加：

- 晨昏弱光窗口 ×1.08（黎明/黄昏摄食峰值）
- 阴天弱光半加成 ×1.04（UV 日峰值 <3 时作用于白天 9–16 时）
- 大雨安全折扣 ×0.85（降水概率 ≥60%，安全/体验决策项，非鱼口结论）
- 闷热低氧、大浪水浑浊度减分
- 气压不参评（Stoner 2004 综述：无对照研究证实气压影响钓获）

指数为相对排序参考，相邻几分之差无意义。

## 数据来源

- **潮汐**：国家海洋信息中心北海港实测预报（经 eisk.cn 抓取，覆盖未来 15 天；超出部分由北部湾全日潮模型估算；钦州 +15 分钟、防城港 +30 分钟相位偏移）
- **天气**：Open-Meteo 实时预报（风、气压、浪高、紫外线、降水概率），断网时回退本地缓存并标注时间
- **鱼种/水温/渔汛**：《广西沿海海钓深度调研报告》（2026-08）+ 全球文献复核（`文献/` 目录）

## 维护（自动化）

数据 freshness 由 macOS launchd 定时任务保障（每周一/周四 10:17）：

```
抓 eisk.cn 未来 15 天潮汐 → 校验农历对齐 → 写回 index.html（自动备份）→ git push 上线
```

手动更新：双击 `更新潮汐数据.command`。运行记录见 `潮汐更新日志.log`。

## 隐私与安全

- 作钓记录和照片只存在各自浏览器 localStorage，不上传任何服务器
- 天气请求由访客浏览器直接发给 Open-Meteo，无中间服务器、无密钥
- 出海前请以国家海洋信息中心潮汐表和气象预警为准；雷雨、大浪不出钓，礁石区高潮前 1 小时撤离，永不独自夜钓
